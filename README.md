# منصة رصد تنفيذ استراتيجية التحول الرقمي

**Digital Transformation Strategy Execution Platform**

منصة تربط الركائز والأهداف بالمبادرات والمشاريع ومؤشرات الأداء، وتتابع تنفيذ استراتيجية التحول الرقمي لحظة بلحظة. واجهة عربية كاملة بدعم RTL، مبنية على هوية الهيئة الرقمية (DGA) وكود المنصات السعودي.

---

## الوظائف

### الهيكل الاستراتيجي المرن
ركائز ← أهداف ← مؤشرات أداء ← مبادرات ← مشاريع ← معالم (milestones). كل مستوى قابل للإضافة والتعديل من داخل المنصة أو عبر الاستيراد من Excel.

### لوحة قيادة تفاعلية
- الإنجاز الفعلي مقابل المخطط على مستوى الاستراتيجية والركيزة والمبادرة والمشروع
- مؤشر أداء عام كمتوسط مرجّح لنسب تحقق المؤشرات
- اتجاه الأداء عبر الأرباع، وأعلى المبادرات إنجازاً، والمشاريع التي تحتاج معالجة
- متابعة الميزانية وكفاءة الإنفاق (الإنجاز ÷ الصرف)

### الخريطة الحرارية — نظام RAG
شبكة مؤشرات × أرباع، قابلة للتجميع حسب الركيزة أو منظور قياس أو المبادرة أو المالك.
تُحتسب نسبة التحقق **من خط الأساس** لا من الصفر، لتعكس التقدم الحقيقي المحرز:

```
اتجاه تصاعدي:  (الفعلي − خط الأساس) ÷ (مستهدف الفترة − خط الأساس) × 100
اتجاه تنازلي:  (خط الأساس − الفعلي) ÷ (خط الأساس − مستهدف الفترة) × 100
```

حدود التقييم قابلة للضبط من إعدادات المنصة (افتراضياً: أخضر ≥ 95%، أصفر ≥ 80%).

### رادار النضج الرقمي
ثمانية أبعاد مؤسسية على مقياس 1–5، مقارنة بالقياس السابق وبالمستهدف، مع مستويات نضج مرجعية من خمس درجات.

### إطار قياس التحول الرقمي — عشرة مناظير
كل مؤشر أداء مرتبط بمنظور من مناظير الإطار، مع درجة لكل منظور ووزن نسبي وتغطية بالمؤشرات.

> **ملاحظة**: مسميات المناظير العشرة مبنية على الفهم العام لإطار قياس التحول الرقمي الحكومي، وهي قابلة للتعديل بالكامل من شاشة «إطار قياس» لمواءمتها مع النسخة الرسمية المعتمدة لدى الجهة.

### نظام صلاحيات بأربعة أدوار

| الدور | الصلاحيات |
|---|---|
| **مدير النظام** | يهيئ الهيكل والمستخدمين والإعدادات، يستورد ويصدّر، يستقبل كل الإشعارات |
| **مدير متابعة الاستراتيجية / مكتب المشاريع** | يتابع كامل المحفظة ويحدّث أي مشروع أو مؤشر، ويستقبل كل الإشعارات |
| **مالك المبادرة / المشروع** | يحدّث مبادراته ومشاريعه فقط: نسب الإنجاز، قيم المؤشرات، حالات المعالم، المستندات |
| **مشاهد التقارير** | يطلع على لوحة القيادة والتقارير ويصدّرها دون أي صلاحية تعديل |

مصفوفة الصلاحيات الكاملة (15 صلاحية × 4 أدوار) معروضة داخل شاشة «إدارة المنصة».

### إدخال حقيقي للبيانات
- **تحديث نسبة تنفيذ المشروع** بشريط تمرير، مع **تعليق إلزامي** (10 أحرف فأكثر) وسجل تحديثات كامل
- **إدخال القيم الفعلية للمؤشرات** لكل ربع، مع **تعليق إلزامي** ومعاينة فورية لنسبة التحقق وحالة RAG
- **تحديث حالة المعالم** مع **مبرر إلزامي عند التأخر**
- **إرفاق مستندات التقدم** (حتى 2 ميجابايت للملف)

### فلاتر على كل الشاشات
الركيزة · الهدف · المبادرة · المشروع · المالك · السنة · الربع · الحالة · الأولوية · المنظور · بحث نصي.
الفلاتر مشتركة عبر الشاشات وتنعكس على التقارير والتصدير.

### نظام إشعارات
تنبيه فوري لمدير النظام ومدير متابعة الاستراتيجية عند كل تحديث ميداني: نسب الإنجاز، قراءات المؤشرات، حالات المعالم، المستندات، تعديلات الهيكل، وعمليات الاستيراد.

### الاستيراد والتصدير
- **استيراد من Excel** عبر قالب جاهز بخمس أوراق وورقة إرشادات؛ الدمج بمطابقة الرمز مع تقرير بالصفوف المتخطاة
- **تصدير XLSX** — تسع أوراق منسّقة RTL: الملخص التنفيذي، الركائز، الأهداف، المبادرات، المشاريع، المعالم، المؤشرات، قراءات المؤشرات، الميزانية
- **تصدير PDF** عبر طباعة المتصفح بتنسيق A4 مخصص — يحافظ على تشكيل النص العربي واتجاه الصفحة دون الحاجة لتضمين خطوط

### التقارير التنفيذية
أربعة قوالب جاهزة للطباعة: التقرير التنفيذي الشامل، تقرير أداء الركائز، تقرير المخاطر والتعثر، تقرير مؤشرات الأداء — بترويسة رسمية ونطاق يعكس الفلاتر المطبقة.

## البنية التقنية

| الطبقة | التقنية |
|---|---|
| الإطار | Next.js 16 (App Router) · React 19 · TypeScript |
| التنسيق | Tailwind CSS v4 مع رموز تصميم DGA |
| الحالة | Zustand مع حفظ في `localStorage` |
| الرسوم | Recharts |
| Excel | ExcelJS (قراءة وكتابة في المتصفح) |
| الأيقونات | Lucide (بديل مؤقت — تُستبدل بمكتبة أيقونات DGA عند توفرها) |
| الخط | Diodrum Arabic (Medium 500 / Semibold 600 / Bold 700) |

### طبقة البيانات
البيانات تُحفظ حالياً في متصفح كل مستخدم عبر `localStorage`، والمنطق كله معزول في ملف واحد: `src/lib/store.ts`.

للترقية إلى قاعدة بيانات مشتركة (Supabase / Postgres / API داخلي): يُستبدل هذا الملف وحده بمناداة الـ API مع الحفاظ على نفس أسماء الإجراءات — دون تعديل أي شاشة.

### هوية DGA
الألوان الأساسية الأربعة (أخضر `#1cc182` · أزرق `#1d9af2` · كحلي `#2a206a` · بنفسجي `#852cd0`) تحمل الهوية، والألوان الثانوية تدعمها دون أن تنافسها — التزاماً بدليل الهوية البصرية للهيئة (v03). النمط الخطي/العُقدي مستخدم بصيغته الرقمية الخفيفة فقط في شاشة الدخول.
